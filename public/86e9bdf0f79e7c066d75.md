IBM Code Engine にデプロイする時、エラーが出てデバッグしたい方向けに情報共有。
公式のドキュメントが結構親切なのでおすすめです。 ↓

https://cloud.ibm.com/docs/codeengine?topic=codeengine-cli

まず、失敗したところ。ブラウザからこんな感じで見える。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/0ff744ca-623c-b790-fc61-941a48ac37a9.png)


GUI で見れない情報もありそうなので、`ibmcloud`コマンドを実行した。

まず、必要なプラグインを入れる（ibmcloud-cli は入ってる前提）。

```bash
ibmcloud plugin install code-engine
```

ログインして、必要な情報を入れていく。ログイン方法はいくつかありそうなので必要に応じて要グーグル。

```bash
ibmcloud login --sso
ibmcloud target -g cc-6620032tyv-cac4436e
ibmcloud ce project select -n cc-6620032tyv-cac4436e-codeengine
ibmcloud ce app get --name hoge-rag
```

`-g`のところはリソースグループ
`-n`のところはプロジェクト
`--name`のところはアプリケーション名

他にもこんなコマンドがある、必要に応じて、それっぽく入力していく。`--instance`の後のインスタンス名はコンテナが動いていれば、上記`ibmcloud ce app get --name hoge-rag`コマンドで表示されるはず。

```bash
ibmcloud ce app events --app myapp
ibmcloud ce app events --instance myapp-atfte-2-deployment-7cb45cdf67-qc7sb
ibmcloud ce app logs --app myapp
ibmcloud ce app logs --instance myapp-atfte-2-deployment-7cb45cdf67-qc7sb
```

ちなみに、デフォルトのポートが8080なので、少し注意。
