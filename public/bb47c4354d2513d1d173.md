# 試行錯誤
まず、こんなエラーメッセージがでた。

```
/usr/local/lib/python3.5/dist-packages/matplotlib/backends/backend_gtk3agg.py:16: UserWarning: The Gtk3Agg backend is known to not work on Python 3.x with pycairo. Try installing cairocffi.
  "The Gtk3Agg backend is known to not work on Python 3.x with pycairo. "
TypeError: Couldn't find foreign struct converter for 'cairo.Context'
```

`cairocffi`って何なのかわからんけど、とりあえず入れてみた。

```
sudo pip3 install cairocffi
```

まだ、エラー出る。

```
TypeError: Couldn't find foreign struct converter for 'cairo.Context'
```
調べると、こんなんひっかかる。
[TypeError: Couldn't find conversion for foreign struct 'cairo.Context' · Issue #221 · rbgirshick/py-faster-rcnn](https://github.com/rbgirshick/py-faster-rcnn/issues/221)
[ノート - FrstGt](https://sites.google.com/site/frstgt/note)
[Python で matplotlib を試そうとしたら 'cairo.Context' ってナニソレ - Qiita](https://qiita.com/5ara5treamer/items/4bf82ada81a3cb30beed)

環境によって対応策違うのかもしれないけど、
`python3-gi-cairo`入れたら良さそうだったので試した。

```
sudo apt-get install python3-gi-cairo
```

これで、実行できた。よかったよかった。
