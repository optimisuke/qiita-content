# ソフトウェア
## OctoPrint
OctoPrintって、ラズパイにのせてリモートで制御したり、プラグインいれて完成時にメール通知したりできるソフトがある。とっても、いい感じ。ただ、3Dプリンタの電源オフ、ラズパイ電源オンの状態だと、液晶画面がオンのままになる。
つけっぱなしでもいいんだけど、気になるからそのうち、どうにかしたい。

### 2023/02/18追記
コメントで対策を教えてもらった＋Redditで割と簡単な対策を発見したので、試すことにした。
[Why Ender 3 LCD stays on even when printer is turned off (while USB plugged into Raspberry pi) : 3Dprinting](https://www.reddit.com/r/3Dprinting/comments/9l2hw8/why_ender_3_lcd_stays_on_even_when_printer_is/)

ケーブルのラズパイに刺す方の端子に写真のように付箋の切ったものを貼り付けると期待通り、電源オフ時に画面がつかないようになった。一度失敗して紙が奥にいってしまったので、ピンセットがあると作業しやすいはず。絶縁できるものなら、なんでも良いと思うけど、自分の場合、机の上にあった付箋を使った。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/f3daaebc-17cc-cc9d-0ca4-c5a8dfa76cfd.png)

# 道具系
改造ではないけれど、便利に使ってるので紹介。

## のり
![IMG_20210410_071733.jpg](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/b6b9492e-d0f5-c5f3-b75f-bd272538c8a8.jpeg)

3Dプリンタは1層目が台にしっかりつくように、いろいろ工夫が必要。シートをはったり、のりをぬったり。
Ender 3 V2はCarborundum Glass Platformとかいうのついてるので、そのままでも結構うまくいく。ただ、細かい部品作ったりするときに、失敗することもある。
そういうとき用に、トンボのシワなしピットってのりを塗ってる。調べておすすめされてたので使ってる。他ののりでも試したことあるけど、こっちはぬりやすくて色も透明でいい感じ。
シート買ってはってもいいのかもやけど、そこそこ値段するし、しばらくはこれで良いかなぁ。
[Ender-3 V2 3D Printer](https://www.creality.com/goods-detail/ender-3-v2-3d-printer)
[Carborundum Glass Platform](https://www.creality.com/goods-detail/creality-carborundum-glass-platform)

[シワなしピット | 株式会社トンボ鉛筆](https://www.tombow.com/products/shiwa_nashi_pit/)

# やっていないこと
## BLTouch
3Dプリンタは使う前にステージの高さの調整するけど、BLTouchってのを使うと調整不要になるらしい。
すごく興味あるけど、まだ試せてない。そこそこ値段するから、悩ましい。
[Ender 3 V2 & BLTouch: How to Install It | All3DP](https://all3dp.com/2/ender-3-v2-bltouch-install/)

## エレキ的なアップデート
エレキ的なところは変更してない。LEDつけて光らせたり、ラズパイの電源をとったりしたい。いつかやりたい。

## ネジとかベアリングをつかう系のアップデート
ネジとかベアリングを使うパーツもあるけど、ネジとかベアリングを選んで買うの大変そうなので、試してない。
ネジのセットを買っちゃうのも手かもなぁ。

# おわりに
3Dプリンタ買って、そこそこたってフィラメント1リール分くらい試した。3Dプリンタ買うときは飽きたらどうしようとか思ってたけど、まだまだ飽きなさそう。コーディングするためのエディタと同じように3Dプリンタも拡張してけるのがとってもいい感じ。ハードウェア的にも拡張できるってなんかすごい。目的と手段が逆になってる気もするけど、自分好みにカスタマイズするの楽しい。まだしばらくは沼から出られなさそう。
