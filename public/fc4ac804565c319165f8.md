# AI Agent からツールを API 呼び出しする

本記事では、AI Agent プラットフォームの watsonx Orchestate と iPaaSの webMethods を使って、PostgreSQL データベースを API 化し、AI Agent から呼び出すまでの流れを解説します。

## 概要

今回のシステム構成は以下の通りです。

- **watsonx Orchestrate**: IBM の AI Agent プラットフォーム
- **webMethods Integration**: IBM の iPaaS（統合プラットフォームサービス）
- **PostgreSQL**: データベース

## OpenAPI 仕様の準備

### 動作確認

まず、作成した API が curl コマンドで正常に動作することを確認します。

```bash
# 辞書API動作確認
curl --fail -X POST "$URL" \
  -H "Authorization: Basic $AUTH" \
  -H "Content-Type: application/json" \
  -d '{"term":"webMethods"}'
```

レスポンス例：

```json
{"definition":"IBMが提供する統合プラットフォーム","term":"webMethods"}
```

### OpenAPI 仕様の作成

OpenAPI を作成します。curlコマンドを伝えて生成AIを活用すると便利です。

```yaml
openapi: 3.0.3
info:
  title: Term Definition API
  version: 1.0.0

servers:
  - url: https://xxx.int-aws-us.webmethods.io
    description: webMethods.io server

paths:
  /runflow/run/sync/v2/xxx:
    post:
      summary: Get term definition
      security:
        - basicAuth: []
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required:
                - term
              properties:
                term:
                  type: string
                  example: "webMethods"
      responses:
        "200":
          description: Success
          content:
            application/json:
              schema:
                type: object
                properties:
                  term:
                    type: string
                    example: "webMethods"
                  definition:
                    type: string
                    example: "IBMが提供する統合プラットフォーム"
        "401":
          description: Unauthorized

components:
  securitySchemes:
    basicAuth:
      type: http
      scheme: basic
      description: "Basic xxx"
```

## まとめ

この構成により、以下のメリットが得られます。

- **データベース連携**: PostgreSQL などのデータベースを簡単に API 化
- **柔軟性**: OpenAPI により様々な AI Agent プラットフォームから利用可能
- **保守性**: webMethods で API のバージョン管理や監視が容易

_補足: 今回インターネット経由でPostgreSQLに接続してますが、webMethods Integration は、オンプレミス環境のデータベースにもエッジランタイムをインストールすることで VPN 不要でインバウンドポートを開けずに安全に接続できます。_

AI Agent とデータベースの橋渡しとして、iPaaS を活用した API 化は有効な手段と言えるでしょう。
