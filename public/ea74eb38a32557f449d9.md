# はじめに

タイトル通りですが、IBM watsonx Orchestrate から IBM Planning Analytics を操作する方法を整理します。

最終的に、こんな感じで、自然言語で操作できます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/2cecb664-bd16-4fd3-af60-fb8c192b20ae.png)

# 設定 

IBM watsonx Orchestrate のエージェント構築画面のDiscoveryからプリビルドエージェントを探していきます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/eccac4a3-956e-4f59-b94a-bc4538ea4287.png)

検索して見つけます。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/78529c76-e3d5-4000-aae7-dee05dd8834c.png)

テンプレートとして利用します。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/1446f946-634d-47b8-afc5-1c54e5aae417.png)

エージェントを作る画面に遷移します。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/9a5653b5-4e1f-42a0-857a-f18d21febf1d.png)

ツールの接続を設定していきます。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/9facfc54-ed47-431d-823b-2fa4f5dfcfe1.png)

Connectorを設定していきます。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/0241c301-e988-4d42-bec4-2a6215125892.png)

2種類のConnectorを編集します。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/b00ce363-8bde-411d-b0e9-608a7dd80ea0.png)

1つ目に、Server URL、User Name、Passwordを入力し、接続を確認し、保存します。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/deb75329-f758-49cb-abbc-1eb37ccca44a.png)

2つ目に、tenant idとmodel nameを入力し、接続を確認し、保存します。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/0bbd8861-1662-4319-a62d-3738134f21f8.png)

tenant id はIBM Planning AnalyticsのURLにありました。
model nameは、データベースの名前を入れることで動きました。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/6883fc7a-f204-4e58-a450-7c254636ce3b.png)

右側のプレビュー画面で動作確認すると以下のように、IBM Planning Analyticsの情報を取得できることがわかります。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/2cecb664-bd16-4fd3-af60-fb8c192b20ae.png)

URL等に誤りがあると、以下のように呼び出しできない場合があります。各入力の確認が必要です。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/184221/2cf744af-a5dc-4b9e-b8a7-008033d8ed9a.png)

# おわりに

無事、接続できました。よかった。
