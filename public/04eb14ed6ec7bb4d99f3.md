# エラー
いつの間にか動かなくなってた。なぜに！？

```
% emacs                                       
dyld: Library not loaded: /usr/local/opt/libffi/lib/libffi.6.dylib
  Referenced from: /usr/local/opt/p11-kit/lib/libp11-kit.0.dylib
  Reason: image not found
zsh: abort      emacs
```

# 対策
[macos - Emacs stop working in Mac OSX Catalina. How to fix? - Stack Overflow](https://stackoverflow.com/questions/59582101/emacs-stop-working-in-mac-osx-catalina-how-to-fix)
を見ると、
`brew reinstall emacs`
で直ったって書いてある。

試したら、動いた。なんやねん。
