# はじめに

IBM watsonx Orchestrateは、AI Agentを構築・運用するためのプラットフォームです。この記事では、シンプルなカスタムツールを作成し、それを使ってAgentを動かす基本的な流れを紹介します。

## 前提条件

開発環境は構築済みとします。環境構築については以下の公式ドキュメントを参照してください：

https://developer.watson-orchestrate.ibm.com/getting_started/installing

## カスタムツールの作成

まずは、基本的な挨拶を返すシンプルなツールを作成してみましょう。

### ツールのコード実装

```python
from ibm_watsonx_orchestrate.agent_builder.tools import tool


@tool
def return_hello(name: str) -> str:
    """
    Returns a greeting with the provided name

    :param name: The name to include in the greeting
    :returns: A greeting string in the format "Hello [name]"
    """

    return "Hello " + name
```

このコードのポイント：

- `@tool`デコレータを使用してwatsonx Orchestrateのツールとして認識させる
- 関数の引数と戻り値の型を明示的に指定
- docstringでツールの説明、パラメータ、戻り値を詳細に記述（これがAgentがツールを理解するための重要な情報になります）

### ツールの登録

作成したツールをIBM watsonx Orchestrate ADK (Agent Development Kit)を使用して登録します。

```bash
orchestrate tools import -k python -f tools/return_hello.py
```

このコマンドで：
- `-k python`: Pythonで書かれたツールであることを指定
- `-f tools/return_hello.py`: ツールファイルのパスを指定

ADKを使用することで、開発したツールを簡単にwatsonx Orchestrateプラットフォームにデプロイできます。

:::note warn
test.pyという名前にすると、なぜかimportできませんでした。
エラーメッセージもなかったので注意です。
:::



## Agentの動作確認

ツールが正常に登録されたら、watsonx OrchestateのWeb UIでAgentを試すことができます。

### Behaviorの設定

Agentに以下のBehaviorを設定します：

```
あいさつされたら、名前を確認してreturn_helloに名前を渡して。
```

### 動作テスト

チャットインターフェースで実際にAgentと対話してみましょう：

## まとめ

この記事では、IBM watsonx Orchestrateでカスタムツールを作成し、Agentに組み込む基本的な流れを紹介しました。

1. **ツール作成**: `@tool`デコレータとdocstringを使用してツールを定義
2. **ツール登録**: IBM watsonx Orchestrate ADKの`orchestrate tools import`コマンドで登録
3. **Agent設定**: Behaviorでツールの使用方法を指定
4. **動作確認**: Web UIでAgentとの対話をテスト

このシンプルな例を基に、より複雑なビジネスロジックを含むツールを作成し、実用的なAgentを構築することができます。watsonx Orchestrateの柔軟なツール機能とADKを活用して、様々な業務に対応するAgentを開発してみてください。以下の記事でもう少し複雑なこともしているので、よかったら読んでみてください。
