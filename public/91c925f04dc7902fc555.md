# 背景
ラズパイ上のMinecraftでプログラミングしてみたい。

# 準備
VNCでMinecraft使えるようにする。
普通に立ち上げると画面がまっくら。
direct capture modeとかいうのを有効にする。

![image.png](https://qiita-image-store.s3.amazonaws.com/0/184221/2ba18556-3f30-b105-7c73-93b3c9cf1a1a.png)

ここを参考にした。
[【Raspberry Pi】Raspbian Jessie with PixelのVNCでマイクラを動かす](https://studio.beatnix.co.jp/kids-it/hardware/raspberry_pi/vnc-minecraft/)

立ち上げれたとこ
![image.png](https://qiita-image-store.s3.amazonaws.com/0/184221/5177f910-4071-6e2f-ac4e-9bd53183bfbb.png)

ただ、ChromebookのVNC Viewerだと、「Relative Pointer Motion」の設定を変えられなさそうなので、視点移動が微妙…。残念。

# コード

pythonで画面に文字列を表示するのと、ブロックを追加するのを試してみた。
```python mc1.py```するだけ。

```python:mc1.py
mc = minecraft.Minecraft.create()
mc.postToChat("Hello World")
pos = mc.player.getPos()
# mc.player.setPos(pos.x, pos.y+100,pos.z)
mc.setBlock(pos.x+1, pos.y,pos.z,1)
```
# 結果
こんな感じ。
目標は達成できた。
「Relative Pointer Motion」を設定変えられなくて、視点が微妙なのが非常に残念…。
