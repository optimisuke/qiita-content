# qiita-content

Qiita articles managed with the official [Qiita CLI](https://github.com/increments/qiita-cli).

This repository stores my published Qiita articles as Markdown files under `public/`.

## Setup

This project uses Volta to pin Node.js.

```bash
npm install
npx qiita login
```

`npx qiita login` requires a Qiita access token with `read_qiita` and `write_qiita` scopes.

## Daily Workflow

Pull the latest articles from Qiita:

```bash
npx qiita pull
```

Start the local preview:

```bash
npx qiita preview
```

Create a new article:

```bash
npx qiita new article-file-name
```

Publish or update one article:

```bash
npx qiita publish article-file-name
```

Publish all changed articles:

```bash
npx qiita publish --all
```

## GitHub Actions

`.github/workflows/publish.yml` publishes articles on pushes to `main` or `master`, and can also be run manually from GitHub Actions.

The repository must have this secret configured:

```text
QIITA_TOKEN
```

## Notes

- Article files are stored in `public/*.md`.
- `public/.remote/` is generated by Qiita CLI and ignored by Git.
- Deleting a Markdown file does not delete the article on Qiita. Delete articles from Qiita directly.
